# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services such as computing, storage, databases, networking, security, analytics, and artificial intelligence. Organizations can use AWS to build, deploy, and manage applications without maintaining all physical infrastructure themselves.

## Global Infrastructure

AWS operates a global cloud infrastructure composed of Regions and Availability Zones. A Region is a geographic area that contains multiple Availability Zones, while Availability Zones consist of separate data centers with independent power, networking, and connectivity.

This infrastructure allows organizations to deploy applications in different geographic locations and design systems for high availability, fault tolerance, and lower latency.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Through the console, users can create virtual machines, configure storage, manage networks, control permissions, monitor services, and perform other cloud administration tasks.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers called instances in the AWS Cloud. Users can configure the operating system and applications that run on these instances.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data. It can be used for backups, websites, data lakes, application files, and big data workloads.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network in AWS. Users can configure IP address ranges, subnets, gateways, routing, and security settings.

### 4. AWS Identity and Access Management

AWS Identity and Access Management (IAM) helps administrators control access to AWS resources. Permissions can be assigned to users, groups, and roles through policies.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased based on application requirements.
2. **Global Infrastructure** – AWS provides multiple Regions and Availability Zones for deploying applications closer to users and improving availability.
3. **Broad Range of Services** – AWS provides services for computing, storage, networking, databases, analytics, security, artificial intelligence, containers, and many other workloads.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

- Hosting websites and enterprise applications
- Running virtual servers and business systems
- Data backup and disaster recovery
- Database hosting
- Data analytics and data lakes
- Application development and testing
- Containerized applications
- Global web applications
