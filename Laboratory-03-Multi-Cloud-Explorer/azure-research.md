# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform that provides services for computing, storage, networking, databases, security, artificial intelligence, analytics, and application development. Organizations can use Azure to build, deploy, manage, and monitor applications and cloud infrastructure.

## Global Infrastructure

Microsoft Azure operates through geographic regions around the world. Many Azure regions support Availability Zones, which are physically separate groups of datacenters within a region.

This infrastructure allows organizations to deploy applications closer to their users and design cloud systems with improved availability and resiliency.

## Cloud Management Console

The Azure Portal is a web-based management console used to create, configure, manage, and monitor Azure resources. Through the portal, administrators can manage virtual machines, storage, networks, databases, security settings, subscriptions, and costs.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources in the cloud. Organizations can run Windows or Linux operating systems and host applications without maintaining physical servers.

### 2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service for the cloud. It is designed for storing large amounts of unstructured data such as images, videos, documents, backups, and application files.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private virtual networks in Azure. It enables communication between Azure resources and can also connect cloud resources with on-premises networks.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and cloud resources. It can be used together with role-based access control to manage permissions and secure access to Azure resources.

## Three Advantages

1. **Microsoft Integration** – Azure integrates well with Microsoft technologies and enterprise environments.
2. **Global Infrastructure** – Azure provides regions and Availability Zones for deploying highly available applications.
3. **Broad Cloud Services** – Azure offers services for computing, storage, networking, databases, analytics, security, artificial intelligence, and application development.

## Typical Enterprise Use Cases

Microsoft Azure can be used for:

- Hosting Windows and Linux virtual machines
- Migrating enterprise applications to the cloud
- Hybrid cloud environments
- Data storage and backup
- Hosting databases and web applications
- Identity and access management
- Artificial intelligence and analytics
- Disaster recovery and business continuity
