# Mission Reflection

After exploring Amazon Web Services, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most was AWS. I was impressed by the wide variety of services it provides and how its services can support different types of organizations, from small startups to large global companies. I also found its approach to scalability and global infrastructure useful for applications that may grow over time.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, networking, identity management, databases, Kubernetes services, and tools for monitoring and security. Although the names of their services are different, many of them perform similar functions. For example, AWS uses Amazon EC2, Azure uses Azure Virtual Machines, and Google Cloud uses Compute Engine for virtual machine workloads.

I learned that business requirements have a major influence on choosing a cloud platform. A company should not simply select the most popular provider. For example, an organization that already uses Microsoft technologies may benefit more from Azure, while an AI-focused company may prefer Google Cloud because of its machine learning and Kubernetes capabilities.

Acting as a Cloud Solutions Consultant helped me understand that cloud decisions require both technical knowledge and an understanding of the client’s needs. I learned to compare services, identify strengths, and recommend platforms based on factors such as scalability, compatibility, cost, and workload requirements.

My GitHub Cloud Computing Portfolio has also improved through this mission. It now contains organized research, comparison tables, client recommendations, Linux investigation results, screenshots, and reflection documentation. This activity helped me practice using GitHub not only for storing files but also for presenting my technical work in a structured and professional way.
