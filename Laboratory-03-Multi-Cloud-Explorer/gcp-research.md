# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly referred to as Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, containers, and application development.

Organizations can use Google Cloud to build, deploy, and manage applications using Google's global cloud infrastructure.

## Global Infrastructure

Google Cloud infrastructure is distributed across locations around the world. These locations are organized into regions and zones.

A region is a specific geographic location where organizations can deploy cloud resources. Regions contain zones, which are deployment areas designed to help improve availability and reduce the impact of infrastructure failures.

Organizations can select regions and zones based on factors such as latency, availability, durability, and geographic requirements.

## Cloud Management Console

The Google Cloud Console is a web-based interface that allows administrators and developers to create, configure, monitor, and manage Google Cloud resources.

Through the console, users can manage virtual machines, storage, networking, databases, Kubernetes clusters, identity permissions, billing, and other cloud services.

## Four Core Services

### 1. Compute Engine

Compute Engine is Google Cloud's Infrastructure as a Service (IaaS) computing service. It allows users to create and run virtual machine instances on Google's infrastructure and supports both Linux and Windows operating systems.

### 2. Cloud Storage

Cloud Storage is Google Cloud's managed object storage service. It stores data as objects inside containers called buckets and can be used for application data, backups, media files, archives, analytics datasets, and disaster recovery.

### 3. Virtual Private Cloud (VPC)

Google Cloud Virtual Private Cloud provides networking functionality for cloud resources such as Compute Engine virtual machines, Google Kubernetes Engine clusters, and serverless workloads.

VPC networks allow organizations to manage private networks, subnets, IP addresses, routing, and connectivity between cloud resources.

### 4. Identity and Access Management (IAM)

Google Cloud Identity and Access Management controls access to Google Cloud resources. IAM allows administrators to define who can perform specific actions on particular resources by assigning roles and permissions.

## Three Advantages

1. **Strong Data and AI Capabilities** – Google Cloud provides advanced services for analytics, machine learning, and artificial intelligence.
2. **Kubernetes Expertise** – Google Cloud provides Google Kubernetes Engine (GKE) for deploying and managing containerized applications.
3. **Global Infrastructure** – Google Cloud offers regions and zones around the world, allowing organizations to deploy applications closer to their users and improve availability.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Hosting virtual machines and web applications
- Artificial intelligence and machine learning workloads
- Big data and analytics
- Containerized applications and Kubernetes deployments
- Object storage and backup
- Application development
- Global networking
- Disaster recovery
