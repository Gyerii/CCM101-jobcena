# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity explores three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity compares their core services, evaluates their strengths, and applies cloud platform selection to different business requirements.

## Cloud Migration of the Linux Server

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from AWS, Microsoft Azure, or Google Cloud Platform.

### Amazon Web Services

**Amazon EC2** could host the Linux server. Amazon EC2 provides virtual computing resources that allow organizations to run Linux-based servers and applications in the AWS Cloud.

### Microsoft Azure

**Azure Virtual Machines** could host the Linux server. Azure Virtual Machines support Linux operating systems and allow organizations to run cloud-based servers without maintaining physical hardware.

### Google Cloud Platform

**Compute Engine** could host the Linux server. Compute Engine provides virtual machines on Google Cloud infrastructure and supports Linux-based workloads.

## Conclusion

Amazon EC2, Azure Virtual Machines, and Google Compute Engine provide similar virtual machine capabilities that can be used to migrate and host this Linux server in the cloud.
