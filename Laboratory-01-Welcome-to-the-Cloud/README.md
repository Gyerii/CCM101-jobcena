# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using the KillerCoda Playground. It focused on basic Linux commands, system information gathering, file organization, GitHub repository management, and Markdown documentation.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Navigate and explore the Linux operating system.
- Gather basic system information.
- Create and organize files and directories.
- Create a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Launched Ubuntu 24.04 using KillerCoda.
2. Created a new Linux user account named `jobcena`.
3. Granted sudo privileges to the new user.
4. Checked the current username, working directory, and hostname.
5. Gathered Linux distribution, kernel, CPU, memory, and disk information.
6. Created folders and Markdown files.
7. Created a public GitHub repository.
8. Organized the laboratory files inside the repository.
